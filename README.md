# LACassie

## Adds the following commands to Local Admin (LA)

lacassie (aliases: "lac", "cassie")  -  Sends an announcement over CASSIE with automatically generated subtitles.

lacassiesilent (aliases: "lacs", "lacassie_silent", "cassie_sl")  -  Sends an announcement over CASSIE without the bells/static, with automatically generated subtitles.

lacassiesubtitles (aliases: "lacsub", "lacassie_subtitles", "cassie_subtitles")  -  Sends an announcement over CASSIE with custom subtitles.

lacassiesubtitlessilent (aliases: "lacsubs", "lacassie_subtitlessilent", "cassie_sl_subtitles")  -  Sends n announcement over CASSIE without the bells/static, with custom subtitles.

**Run the commands without arguments to see the usage response.**

## Config
Debug Mode - Enables the logging of debug messages (ex: "Sending CASSIE silent announcement with subtitles")
